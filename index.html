▣ Windows EXE · GitHub Build Server

Convert the current Forge scene into a project JSON compatible with your separate Windows build server.

Build server: etahroll5/Forge-Game-Engine-Build-Server

  1. Download or copy the build-server JSON.
  2. Open Forge Windows Build workflow.
  3. Choose Run workflow, paste the JSON into project_json, and start the build.
  4. Download the Windows EXE artifact after the workflow succeeds.

GitHub's workflow input is limited to 45 KB. Large scenes may not fit. A one-click server build would require a secure backend connection.
